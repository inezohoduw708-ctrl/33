# Черепашки-ниндзя: Тени Нью-Йорка

Полноценный 3D-экшен про Черепашек-ниндзя в браузере: улицы Нью-Йорка, четыре играбельные
черепашки с разными приёмами, комбо-боёвка, волны Клана Фут, босс Шреддер и сохранение прогресса.
Всё нарисовано кодом (процедурные модели, текстуры, эффекты и звук) — ни одного внешнего ассета,
поэтому игра мгновенно грузится и работает офлайн.

Оптимизировано под **Яндекс Браузер** (Chromium/Blink, WebGL2), но идёт и в Chrome, Firefox, Edge.

---

## Как запустить

```bash
npm install
npm run dev        # http://localhost:5173 — разработка (HMR)
npm run build      # сборка в dist/ (относительные пути)
npm run serve      # http://localhost:8080 — готовый статичный сервер: / = запуск игры, /play = сразу игра
npm run preview    # альтернативный предпросмотр средствами vite
```

**Один файл без сервера:** `npm run single` собирает `game.html` — самодостаточный HTML
(~660 КБ): JS упакован в классический скрипт (IIFE, без ES-модулей) и вместе с CSS встроен
в страницу. Работает по `file://` двойным щелчком, в песочнице iframe и в любой панели
предпросмотра — сервер и внешние запросы не нужны.

Требования: браузер с включённым аппаратным ускорением (WebGL2) и Node.js 18+ для сборки.
Собранная папка `dist/` — обычная статика: её достаточно положить на любой хостинг
(или открыть `dist/index.html` через локальный сервер); никакого бэкенда не нужно.

## Управление

| Клавиши | Действие |
| --- | --- |
| `W A S D` | бег по улице (относительно камеры) |
| `ЛКМ` / `J` | серия ударов — комбо из трёх (третий — разворот) |
| `K` | тяжёлый удар: пробивает блок, сбивает с ног |
| `L` | спецприём черепашки (нужна энергия) |
| `Пробел` | прыжок |
| `Shift` | рывок с неуязвимостью |
| `E` | подобрать пиццу / мутаген / кристалл |
| `Q` / `Tab` / `1`–`4` | смена черепашки |
| `←` `→` / `,` `.` / ПКМ+мышь | вращение камеры |
| `H` | подсказка по управлению (игра ставится на паузу) |
| `Esc` / `P` | пауза |
| `M` | звук |
| тач | виртуальный стик + кнопки (появляются на мобильных) |

Диагностика: откройте игру с `?debug=1` — в углу появятся FPS, число врагов и позиция.

## Что есть в игре

**Боёвка**
- трёхударные комбо со замахом, активной фазой и восстановлением; четвёртый удар в серии — с разворотом;
- тяжёлый удар с пробитием защиты, отбрасыванием и микро-фризом кадра (hit-stop);
- рывок с i-frames, авто-доводка на ближайшего врага в конусе;
- счётчик комбо: растёт, пока серия не прервана; множитель очков и энергия за попадания;
- спецприёмы на 100% энергии: вихрь катаны (Лео), рывок-ярость (Раф), удар посохом-волна (Дон),
  нунчаку-смерч с движением (Майки);
- телеграфы атак врагов (красное кольцо), стаггер, стрелки с бластерами, громилы с клинком.

**Разное**
- между волнами открывается люк-портал: следующий бой начинается, когда игрок сам в него шагнёт;
- каждая глава со своими модификаторами (урон, скорость и живучесть врагов, доля стрелков);
- экран паузы со статистикой забега, экран поражения, баннер выхода босса.

**Мир**
- процедурная улица Нью-Йорка: небоскрёбы с окнами и неоновыми вывесками, пожарные лестницы,
  водонапорные башни, фонари, светофоры, гидранты, припаркованные и проезжающие машины,
  пар из люков, лужи, граффити, дождь и молнии в третьей главе;
- три времени суток (ночь, закат, гроза), объёмный туман, тени, rim-подсветка силуэтов;
- автоматическое понижение качества при просадке FPS (меньше теней, разрешение, дождь).

**Персонажи**
- 4 черепашки с разными цветами масок, оружием (катаны, саи, посох, нунчаку — по паре),
  характеристиками и спецприёмами;
- риги с полноценной анимацией: бег, стойка, замах, серия ударов, разворот, прыжок, урон, нокаут,
  развивающиеся концы бандан;
- Клан Фут: лёгкие бойцы, тяжёлые, стрелки и громилы (у каждого свой силуэт и поведение);
- **Шреддер** — босс с тремя фазами, рывками, ударными волнами, призывом подкрепления и
  уязвимостью к ударам в спину.

**Прогресс**
- 4 главы с волнами врагов и финальным боссом;
- сохранение в `localStorage`: открытые главы, текущая глава, рекорд, лучшие ранги (D–S),
  суммарные победы, выбранная черепашка, настройка звука, время в игре;
- экран результатов с рангом, статистикой и разблокировкой следующей главы;
- «Продолжить», «Новая игра», выбор глав, экран управления, пауза, экран поражения.

## Технологии

- **TypeScript + Vite**, рантайм — только **three.js** (WebGL2, PCF-тени, ACES-тонмаппинг).
- Модели, текстуры, неоновые вывески, граффити и частицы генерируются в коде (`CanvasTexture`,
  `BufferGeometry`), поэтому нет загрузки ассетов и мгновенный старт.
- Звук полностью синтезируется через WebAudio API (шумы, тоны, фильтры, процедурный бас-риф),
  включается после первого действия пользователя — как того требуют браузеры.
- Игровой цикл с фиксированным бюджетом кадра, hit-stop, тряска камеры, пулинг частиц.

## Структура проекта

```
src/
  main.ts            вход: меню, экраны, сохранения, кнопки
  game/
    game.ts          оркестратор: главы, волны, босс, камера, HUD, качество
    player.ts        контроллер черепашки: движение, комбо, спецприёмы, рывок
    enemy.ts         ИИ Клана Фут и босс Шреддер (фазы, рывки, ударные волны)
    models.ts        процедурные риги: черепашки, враги, Шреддер, анимации
    fx.ts            частицы, слаш-трейлы, телеграфы, всплывающие цифры урона
    camera.ts        камера от третьего лица с орбитой и авто-доводкой
    levels.ts        дизайн четырёх глав
    pickups.ts       пицца, мутаген, кристалл энергии
    context.ts       общий контекст боя
  world/city.ts      процедурный Нью-Йорк, свет, погода, коллизии
  core/              ввод, аудио, ассеты-текстуры, утилиты
  ui/hud.ts          HUD: карточки черепашек, объектив, комбо, босс-бар
index.html           разметка экранов + стили интерфейса в src/style.css
tests/               headless-проверки (см. ниже)
```

## Тесты

Игра проверяется без браузера: jsdom + заглушка WebGL-рендерера, поэтому прогоняется настоящая
симуляция (волны, бой, босс, сохранения).

```bash
npm run test:smoke   # загрузка глав, бой, смена черепашек, пикапы, смерть, босс
npm run test:boot    # запуск реального main.ts: экраны, кнопки, пауза, localStorage
npm run test:play    # бот проходит все 4 главы до финала
npm run test:leak    # 8 перезагрузок глав + 90 с случайного ввода: утечки, стабильность
npm run test:all     # всё сразу
npm run test:single  # запуск самодостаточного game.html в эмуляции браузера
```

Скриншоты для визуального контроля (в `shots/`): программный raycast-рендер сцены в PNG —
`npm run shots`.
